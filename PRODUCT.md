# BIX
<!-- impeccable:product-schema 1 -->
## Platform
web
## Users
Daky and individual traders recording daily broker account performance on desktop and mobile.
## Product Purpose
A local-first manual trading journal: brokers, balances, cash-flow-adjusted performance, goals and hypothetical projections.
## Capabilities and Constraints
React/TypeScript PWA. Preserve version-1 browser data and backups. No brokerage credentials, execution, cloud sync or invented statistics. Goals have freely selected start and end dates. Installable on supported browsers, with honest fallback instructions.
## Brand Commitments
BIX identity retained. User selected a dark cyan dashboard inspired by supplied trading dashboards, with an equivalent light theme. Keep useful data hierarchy, chart and journal, not simulated AI coaching or market feeds.
## Operating Context
Manual daily entry; offline usage after first cached visit; periodic private JSON backups. GitHub destination Dawensky009/Bix, commit and push each tested change batch when authentication permits. No production deploy requested.
